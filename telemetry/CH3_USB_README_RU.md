# Chiller 3: USB-обновление до ch3-msi-2

Живая телеметрия ch3-msi-1 уже использует MSI. После удаления Cloud будущая установка новой прошивки требует USB: установленная MSI-1 проверяет старый адрес загрузки Supabase. После USB-перехода на MSI-2 дистанционное программирование включится автоматически. Не отключать питание самого чиллера или PLC для этой операции: речь об отдельном ESP32-шлюзе связи.

Закрытый пакет `ch3-usb`: `C:\Users\Owner\AppData\Local\FarmplastMsi20261116\ch3-usb`; копия на MSI — `E:\SimScopeData\Farmplast\NJTelemetry\private\firmware-20261116\ch3-usb`. Файл приложения содержит Wi-Fi и ключи, пакет и полную резервную копию flash не публиковать. Образ `ch3-msi-2`, 1 137 520 байт, SHA-256 `63fbe52864a0835ca02c4596a617b9b722cec6909b13b3be3d9a1c5b16a27010`.

1. Сверить отдельную плату ESP32, её Ethernet/PLC-подключение и исходник с рабочим шлюзом Chiller 3. Этот пакет консервативно принимает только ESP32 с 4 MB flash. Другая модель, объём памяти или разметка требуют отдельной проверки; запись остановится.
2. Определить фактический COM-порт в диспетчере устройств и закрыть Serial Monitor. esptool временно перезапускает только подключённый шлюз. Первый порт автоматически не выбирается.
3. Проверка без оборудования: `powershell -NoProfile -ExecutionPolicy Bypass -File .\install-ch3-usb.ps1`. Она проверяет все SHA и не открывает COM. Параметр действует только для этого процесса, настройки Windows не меняются.
4. Идентификация без записи: добавить `-Port COM7 -Inspect`, заменив COM7 фактическим портом.
5. После физической сверки платы и исходника: добавить `-Port COM7 -Install -BoardConfirmed -SourceConfirmed`. Сначала создаётся полная закрытая резервная копия 4 MB flash. Вся существующая таблица разделов сравнивается с проверенной MSI-1/MSI-2. Несовпадение останавливает запись.
6. При совпадении записываются только приложение app0 и служебный выбор app0, затем выполняется проверка esptool. Загрузчик, таблица разделов, NVS, Ethernet/Wi-Fi настройки, калибровки и файловая система сохраняются. Полное стирание не используется.
7. Проверить версию ch3-msi-2, новую загрузку и свежие прямые данные на сайте. Три чиллера должны быть онлайн. После появления MSI-2 блокировка удалённого программирования снимается автоматически. Ошибку прежнего OTA не считать подтверждением USB-установки: проверять текущую версию и живые данные.

Пакет проверен автономно: полный checksum, добавленная SHA, модель/версия, запас OTA и совпадение разметки со сборкой MSI-1. Реальное USB-подключение, чтение flash, запись и восстановление пока не испытаны. При ошибке остановиться и сохранить резервную копию; автоматическое восстановление скрипт не выполняет.
