# Прямой перенос трёх чиллеров на MSI

Все три прошивки установлены 16 ноября 2026 (America/New_York) в порядке CH2 → CH3 → CH1 после разрешения владельца. Для каждого устройства проверены новая версия, новый boot ID, прямое получение на MSI и завершённое задание OTA. Сайт читает живые показания с MSI; старые показания чиллеров удалены из Supabase.

Проверены исходные производственные образы, совпадение ключей с сервером, ESP32 core 3.3.8, модель и версия внутри образа, таблица разделов, полный checksum, добавленная SHA и запас не менее 64 KiB. Исходники сохранены в `firmware/msi`. Пины, чтение датчиков/PLC и автоматическая логика выходов сохранены; меняются транспорт и версия прошивки. Команды выходов, уставок и reset при проверках не отправлялись.

Телеметрия новых образов: устройство → `https://farmplast.vercel.app/api/nj-ingest/chiller-N` → защищённый MSI. Показания хранятся только в RAM. Существующие служебные OTA/control RPC Supabase сохраняются, потому что Farmplast Auth, кадровые данные и закрытое хранилище обновлений остаются отдельными действующими частями проекта.

Образы доставлены действующим механизмом через **закрытые** bucket `ch1-firmware` / `chiller-firmware` Farmplast, с чтением сохранённых байтов обратно и проверкой SHA перед одобрением. Образы содержат текущие Wi-Fi/OTA credentials и новые ключи MSI; их нельзя публиковать в открытом Git или общедоступном хранилище. Права доступа к bucket не расширялись.

Каждый контроллер кратковременно перезагрузится. После каждого обновления проверяются целевая версия, новый boot ID, реальные пакеты с транспортом direct, завершение OTA и работа сайта. Следующий чиллер обновляется только после успеха предыдущего. Команды вентилятора, reset и уставки в проверке не отправляются. Код программирования вводится владельцем непосредственно в форме Farmplast и не передаётся в чат.

Проверенные файлы находятся локально в `C:\Users\Owner\AppData\Local\FarmplastMsi20261116\build\ch1`, `ch2`, `ch3`. Только файлы `ChillerN.ino.bin` являются OTA-приложениями; merged/bootloader/partition images через OTA не используются.
