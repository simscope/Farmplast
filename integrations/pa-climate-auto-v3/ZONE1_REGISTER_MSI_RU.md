# BF:90 → Zone 1: актуальная процедура

Прежнее одноразовое исключение для `PA-CLIM-209BA98CD258` отменено: эта плата теперь относится к Zone 3 и не переносится.

Целевая плата Zone 1: `PA-CLIM-209BA98DBF90` (MAC `20:9B:A9:8D:BF:90`), серверная уставка 50 °F. До подтверждения назначения режим OFF.

Использовать общий механизм из [REPLACEMENT_RU.md](REPLACEMENT_RU.md): сайт → Programming & diagnostics → Replace controller · Zone 1 → Prepare replacement → Download / resume Windows USB setup.
На Windows-ПК возле BF:90 распаковать ZIP и запустить Run-Replacement.cmd. Старый Provision-Zone1-Already-Flashed.ps1 для CD258 не использовать.

Индивидуальный профиль выдаётся только после USB-проверки MAC/модели и сохраняется DPAPI. Версия безопасного ожидания назначения — 2.1.0. При старой версии мастер предложит резервное копирование и обновление приложения без стирания NVS. Адрес сервера, CA и ключи вручную не вводятся.

USB PROVISION PASS, ONLINE, ACK уставки 50 °F и окончательное назначение — отдельные шаги. До реальной телеметрии BF:90 аппаратная настройка не считается завершённой. Zone 2–4 не перепривязывать.
