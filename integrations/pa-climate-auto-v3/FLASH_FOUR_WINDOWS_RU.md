# Заводская установка

Используйте автоматический порядок из README_RU.md: Farmplast → Climate Control → Add controller → ZIP → Add-ESP32.cmd на заводском Windows ПК.
Не правьте .ino/URL/CA/JSON вручную. Не используйте домашний MSI для USB.
Сначала одна новая плата с двумя DS18B20; оставшиеся — после реальных команд, OTA и восстановления на первой. Действующая Zone 1 защищена.
