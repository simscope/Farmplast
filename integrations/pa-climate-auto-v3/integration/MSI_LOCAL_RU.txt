Состояние установки 10 ноября 2026

MSI работает только сервером. ESP32 по USB подключается к заводскому Windows-компьютеру.
Существующий gateway: supabase-envoy, 127.0.0.1:18000 -> 8000 в существующем контейнере.
Climate выполняется внутри существующего MAIN worker supabase-edge-functions (Deno), через createClimateHandler и Fetch-адаптер. Новых процессов-серверов, контейнеров, служб, таблиц и портов нет.

GET /climate/healthz: 200. POST /climate/v1/exchange: индивидуальный device bearer.
GET /climate/v1/firmware/<sha256>: только действующая подписанная ссылка для доставленного OTA job.
GET/POST /climate/v1/admin/*: всегда 404, даже с правильным admin key.
/climate/operator/*: проверка существующего Farmplast JWT через Supabase Auth + UUID allowlist из существующего SACS_SSO_ALLOWED_USER_IDS проекта Farmplast. Регистрация устройств и выдача их секретов через этот браузерный API запрещены.
/climate-local/v1/admin/*: только локальное управление с закрытым admin key. Этот namespace запрещено включать в публичный HTTPS ingress.
/climate/workstation/*: одноразовый enrollment ticket, затем отзывная ограниченная учётная запись заводского установщика. Доступны регистрация новых устройств и проверка ONLINE; управление отоплением и OTA недоступно. pa-zone-1 зарезервирована.
